# specフォルダ

このフォルダには、詳細設計に相当する文書を格納します。

## ディレクトリ構造

```
spec/
├── screens/         # 画面単位の仕様
└── business-logic/  # ビジネスロジック単位の仕様
```

## 基本方針

- 画面仕様は `screens/`、ビジネスロジック仕様は `business-logic/` に分ける
- 1ファイル1対象で管理し、複数対象を1つのファイルにまとめない
- 基本設計で定義した共通ルールを前提に、対象固有の挙動を記述する

## 作成方法

- 詳細設計を作成するときは `create-spec` スキルを使う
